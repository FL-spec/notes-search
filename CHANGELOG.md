# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow
[Semantic Versioning](https://semver.org/).

## 1.1.0

### Changed

- The Apple Notes import includes notes in Recently Deleted again, because Notes' own search
  returns them (checked in Notes.app on macOS 26). Use `--skip-deleted` to leave them out.
  `--include-deleted` is still accepted and now does nothing.

### Added

- `docs/validation.md` records a second Notes.app comparison: 23 searches over the synthetic
  corpus, all identical.

## 1.0.2

### Fixed

- The Apple Notes import no longer indexes notes in Recently Deleted. The folder is recognised by
  its name in any of the 42 languages Notes ships. Use `notes-search index apple-notes
  --include-deleted` to keep them.

### Changed

- CI tests Python 3.10 through 3.14.
- Documentation corrections: every command and claim was rechecked against the code and
  measurements.

## 1.0.1

### Fixed

- A search whose first word can't match (for example `notes.`) crashed the CLI when another pass,
  such as `--fuzzy`, still returned results.
- Snippets of short notes are no longer cut mid-line, and highlighting no longer includes the
  punctuation around a word.

### Added

- Linting, formatting and type checking (`ruff`, `mypy`) in CI, and a `py.typed` marker.
- Code of conduct, security policy, issue forms, a pull request template and Dependabot for
  GitHub Actions.
- A rendered demo and a pipeline diagram in the README, generated by `scripts/render_demo.py`.

## 1.0.0

First public release.

- Matching follows the query Notes runs, `"*search*"cwdt`: the first word matches
  inside words, later words match word starts, word order is free.
- Text is tokenized the way Spotlight indexes it: compounds such as `alpha-beta`, emails, URLs
  and numbers are searchable whole and in parts, camelCase and letter/digit runs are split, and
  apostrophes follow Spotlight's contraction and elision rules. Checked against Spotlight on a
  417-query synthetic corpus.
- Notes' sort order: exact title, notes before attachments, newest first. The first two results
  are Top Hits.
- Date phrases with Notes' calendar semantics ("last month" starts on the 1st of the previous
  month).
- Filter tokens (`--has`), attachment results with their parent notes, locked notes by title.
- Notes' ranking weights, age buckets and the two unused sort strategies (`--strategy`).
- The switched-off passes, available as options: Spotlight's `f066` fuzzy matcher (`--fuzzy`),
  spell-checker expansion (`--spell`), spelling and lemma queries (`--spell-api`) and related
  words (`--related`).
- Sources: folders of text and Markdown files, JSON, and Apple Notes with folders and accounts.
- `query` and `spotlight` commands to print Notes' query or run it on files with `mdfind`.
